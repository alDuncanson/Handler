# Handler

Handler is an open-source [A2A protocol](https://github.com/a2aproject/A2A)
client for people building, testing, and operating agentic systems.

Use Handler when you need to:

- explore A2A agents interactively from a terminal UI
- send messages, stream events, and manage tasks from scripts
- inspect and validate agent cards before debugging deeper protocol issues
- expose Handler as MCP tools so other agents can call A2A services
- save reusable global or repository-local server definitions with enterprise auth

## Install

```bash
uv tool install a2a-handler
```

Or with `pipx` or `pip`:

```bash
pipx install a2a-handler
# or
pip install a2a-handler
```

## First commands

```bash
handler tui
handler card get --url http://localhost:8000
handler message send --url http://localhost:8000 --text "hello"
handler mcp
handler docs
```
