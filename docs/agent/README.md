# Agent Documentation

This directory contains agent-oriented documentation for operating and developing `handler`.

1. `agent-dx-contract.md` defines expected machine-readable behavior, validation, and compatibility guarantees.
1. `CONTEXT.md` captures context-window-safe execution patterns for agents.
1. Repository-local skill packs live in `.agents/skills` for development, testing, and release workflows.
1. MCP runtime smoke expectations (localhost flow and terminal-task semantics) are documented in `AGENTS.md` and reflected in skill guidance.

For protocol reference material, use `docs/spec/a2a`.
